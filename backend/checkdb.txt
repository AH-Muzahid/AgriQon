সবচেয়ে Important — Referential Integrity Check

Faker অনেক সময় invalid relation generate করে।

Run করুন:

SELECT COUNT(*)
FROM order_items oi
LEFT JOIN orders o ON o.id = oi.order_id
WHERE o.id IS NULL;

এবং:

SELECT COUNT(*)
FROM payments p
LEFT JOIN invoices i ON i.id = p.invoice_id
WHERE i.id IS NULL;

Result ideally:

0

হওয়া উচিত।

2. Inventory Consistency Test (VERY IMPORTANT)

এইটা ERP এর heart।

Run:

SELECT
    id,
    total_stock,
    reserved_stock,
    available_stock,
    (total_stock - reserved_stock) AS calculated
FROM inventory
WHERE available_stock != (total_stock - reserved_stock);

Result ideally empty হওয়া উচিত।

কারণ trigger auto-calculate করছে।

8. Order Total Validation

Run:

SELECT
    o.id,
    o.total_amount,
    SUM(oi.subtotal) AS calculated
FROM orders o
JOIN order_items oi ON oi.order_id = o.id
GROUP BY o.id
HAVING o.total_amount != SUM(oi.subtotal);

Mismatch থাকলে seed logic broken।

9. Payment Ledger Validation

Run:

SELECT
    i.id,
    i.paid_amount,
    COALESCE(SUM(p.amount), 0) AS calculated
FROM invoices i
LEFT JOIN payments p ON p.invoice_id = i.id
GROUP BY i.id
HAVING i.paid_amount != COALESCE(SUM(p.amount), 0);

এইটা very important financial integrity check।
